# Casio 计算器在线版

在浏览器中复刻 **卡西欧 fx-991EX ClassWiz** 科学计算器：自然显示（Natural V.P.A.M.）、完整键盘布局、可用的科学函数。

**在线体验：** https://casio-calculator-taupe.vercel.app

**[English](README.md)** | **中文**

## 技术栈

- React + TypeScript + Vite
- 完整 fx-991EX ClassWiz 按键布局（SHIFT / ALPHA / MODE、分数、三角、对数、统计）

## 开发

```bash
npm install
npm run dev      # 本地开发服务器
npm run build    # 生产构建
```
