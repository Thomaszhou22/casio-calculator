# Casio Calculator Online

An online recreation of the **Casio fx-991EX ClassWiz** scientific calculator, rebuilt in the browser with natural display (Natural V.P.A.M.), full keyboard layout and working scientific functions.

**Try it live:** https://casio-calculator-taupe.vercel.app

## Tech Stack

- React + TypeScript + Vite
- Full fx-991EX ClassWiz button layout (SHIFT / ALPHA / MODE, fractions, trig, logs, statistics)

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
```
